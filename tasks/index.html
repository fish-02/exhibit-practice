課堂任務卡

回展覽首頁｜速查表

卡關時

  1. 先比對任務卡的「完成檢查」和「常見問題」，最多 2 分鐘。
  2. 開麥告訴講師，或把截圖貼到 Meet 聊天室，格式：s03｜任務 2｜我做了什麼｜看到什麼。
  3. 講師處理不到時，先用「進度檔」跟上，問題課後再處理。進度檔只補作品檔案，Commit 和 Push 還是要自己完成。

下面的 s01 都要換成你的編號。

任務 0：把練習檔案拿到電腦上

20:30 提早進會議的人先做；其他人在開場後的任務 0 時間完成。

  1. 打開 GitHub Desktop，選 File → Clone repository → URL。
  2. 貼上講師在聊天室提供的 repo 網址，按 Clone。
  3. 按 Open in Visual Studio Code。

完成檢查：VS Code 左側看得到 works 資料夾。

常見問題：找不到 VS Code 按鈕時，可在 VS Code 選「檔案 → 開啟資料夾」，打開 GitHub Desktop 顯示的 Local path。

任務 1：幫作品標上 HTML 結構

打開 works/s01/index.html，只加標籤，不改文字：

  1. 作品名稱用 <h1>；作者與每段內文用 <p>。
  2. 把圖片說明換成 <img src="images/cover.svg" alt="潮間帶抽象插圖">。
  3. 引文用 <blockquote>，每行後面加 <br>（最後一行不用）。
  4. 內容用 <main> 包起來，最後一句聲明放進 <footer>。

存檔（Ctrl+S）後，在檔案總管雙擊 index.html 用瀏覽器打開；之後改完存檔，按 F5 重新整理。

完成檢查：圖片有出現、引文分成 3 行。可對照完成範例的結構。

常見問題：圖片破圖時，檢查路徑是不是 images/cover.svg；畫面沒變時，確認有存檔。

進度檔：複製 progress-files/s01/1-html-done.html 的全部內容，貼進自己的 index.html。

任務 2：用 CSS 和 F12 調整閱讀體驗

  1. 在作品頁按 F12，選左上角的箭頭工具，再點內文。
  2. 在 Styles 區試著加上 line-height: 1.9;。這裡的修改重新整理就會消失。
  3. 按 Ctrl+Shift+M 開啟手機模式，看看圖片有沒有超出畫面。
  4. 把下面的內容加進自己的 style.css 並存檔。
body {
  max-width: 680px;
  margin: 0 auto;
  font-size: 18px;
  line-height: 1.9;
}

img {
  max-width: 100%;
  height: auto;
}

完成檢查：內文不擠，手機模式下沒有左右捲動。

常見問題：規則沒生效時，檢查大括號、冒號、分號是否是半形。

進度檔：複製 progress-files/s01/2-css-done.css 的全部內容，貼進自己的 style.css。

任務 3：用 GitHub Desktop 存一個版本

  1. 點上方 Current Branch → New Branch，名稱填 s01，按 Create Branch。如果跳出詢問，選擇把變更帶到新分支（Bring my changes）。
  2. 在 Changes 分頁確認：所有變更都在 works/s01/ 底下。
  3. 左下角 Summary 寫 完成作品頁結構與排版，按 Commit to s01。
  4. 按上方 Publish branch。
  5. 到 History 分頁，看到剛才的版本。

完成檢查：History 看得到剛才的版本，而且上方按鈕不再顯示 Publish branch。

看講師示範：刪掉一段文字後，在 History 對該版本按右鍵選 Revert Changes in Commit，文字就會回來。這一步不用跟著做，課後可以自己試。

常見問題：沒有 push 權限時，到 Email 或 GitHub 接受協作者邀請。

備案：Desktop 無法使用時，在 GitHub 的 repo 頁面按鍵盤 . 開啟 github.dev，並跟著講師操作。

任務 4：請 AI 修改，再檢查它改了什麼

課堂統一建議用網頁聊天型 AI；習慣用編輯器型的人也可以，但指令要限定只能改自己的資料夾。

把 style.css 全部內容貼給 AI，並附上這段指令：

這是一個文學作品頁的 CSS。請只幫我設定 blockquote 的樣式：
上下留白 32px、左內距 20px、左邊框 4px、顏色 #c8553d。
不要改動其他規則，不要加入新檔案，也不要新增外部資源。
請回傳完整 CSS。
  1. 把結果貼回 style.css，存檔並重新整理。
  2. 到 GitHub Desktop 的 Changes 檢查：只改到 works/s01/style.css，而且只新增了 blockquote 規則。
  3. 確認無誤後 commit、push。

完成檢查：引文左側有紅色線條，其他文字內容沒有變。

進度檔：複製 progress-files/s01/3-ai-done.css 的全部內容，貼進自己的 style.css。

任務 5：發 Pull Request

講師會依進度決定大家一起發，或先看示範。如果改看示範，學員的 Pull Request 由講師課後協助。

  1. 確認 GitHub Desktop 已 push，再按 Create Pull Request（或 Preview Pull Request）。
  2. 在瀏覽器確認 base 是 main、compare 是 s01，按 Create pull request。
  3. 對照下面 3 項自我檢查，並把連結貼到 Meet 聊天室。
  • Files changed 只有 works/s01/ 底下的檔案。
  • 作品文字沒有被改動或刪除。
  • 內容開頭寫一句：我改了什麼。

完成檢查：講師合併後，等待 1 到 10 分鐘，展覽網站上的作品會更新。
